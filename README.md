> **Zen** is a privacy-first, full-stack mental health support platform that combines evidence-based psychological coping strategies with advanced Retrieval-Augmented Generation (RAG) AI, real-time token streaming, agentic context fusion, and field-level AES-256 data encryption.

---

## 🌟 Key Architecture & Features

### 🤖 1. Real-Time Streaming RAG Chatbot (LLaMA 3.3 70B)
- **Token Streaming via SSE**: Uses Server-Sent Events (SSE) to deliver AI response tokens instantly as they are generated by Groq's LLaMA 3.3 70B engine.
- **Local Embedding Vector Pipeline**: Powered by LangChain and `@xenova/transformers` (`all-MiniLM-L6-v2`) running locally in Node.js for free, zero-latency vector similarity retrieval.
- **Conversational Memory**: Automatic session history persistence via MongoDB `MongoDBChatMessageHistory`.

### 🧠 2. Agentic Context Fusion
- **Cross-Feature Awareness**: Chatbot automatically queries the user's recent mood logs and journal entries to build personalized system prompt context, offering tailored emotional support (*"I noticed your mood was lower yesterday after work..."*).

### 🛡️ 3. Crisis Detection Safety Middleware
- **Emergency Interception**: Intercepts high-risk keywords (e.g. self-harm, suicide) before passing input to the LLM, immediately returning verified crisis helpline payloads (iCall, AASRA, Vandrevala Foundation).

### 🔒 4. Zero-Knowledge Field-Level Encryption (AES-256-GCM)
- **Data Privacy Assurance**: All sensitive user journal entries are transparently encrypted using **AES-256-GCM** before database insertion and decrypted on retrieve. Plaintext data never resides unencrypted on disk.

### 📊 5. Mood & Journal Analytics
- **Mood Tracking**: Log daily emotional valence (scale 1-5), notes, tags, and activities with interactive visual charts (Chart.js).
- **Rich Journaling**: CRUD diary entries with tag filtering, search, and date range filters.

### 🧘 6. Guided Breathing Exercises
- Interactive visual cues for box breathing, 4-7-8 relaxation, and custom pacing to regulate the nervous system during acute distress.

## 📡 API Endpoints

### 💬 Chatbot & AI
- `GET /api/chatbot/messages` — Fetch chat history
- `POST /api/chatbot/message` — Standard JSON RAG response
- `POST /api/chatbot/stream` — **SSE real-time token streaming RAG response**
- `DELETE /api/chatbot/messages` — Clear chat history

### 📝 Journaling (AES-256 Encrypted)
- `GET /api/journal` — Fetch encrypted journal entries (auto-decrypted in memory)
- `POST /api/journal` — Create new encrypted journal entry
- `PUT /api/journal/:id` — Update journal entry
- `DELETE /api/journal/:id` — Delete journal entry

### 📊 Mood Tracker
- `GET /api/mood` — Fetch user mood log history
- `POST /api/mood` — Log new daily mood entry

### 🔑 Auth & Users
- `POST /api/users/register` — Register user
- `POST /api/users/login` — Login & receive JWT

## 🚀 Getting Started

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **MongoDB**: Connection URI (or run with mock fallback mode)
- **Groq API Key**: Get a free API key from [Groq Console](https://console.groq.com)

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/vaishnavk09/Zen-v2.git
   cd Zen-v2
   ```

2. **Setup Server Environment Variables**
   Create a `.env` file in the `server/` directory:
   ```env
   PORT=5000
   NODE_ENV=development
   MONGODB_URI=your_mongodb_atlas_connection_string
   JWT_SECRET=your_jwt_secret_key
   GROQ_API_KEY=your_groq_api_key
   ENCRYPTION_KEY=your_32_byte_aes_encryption_key
   SKIP_MONGO=false
   ```

3. **Install Dependencies**
   ```bash
   # Install server dependencies
   cd server
   npm install

   # Install client dependencies
   cd ../client
   npm install
   ```

4. **Run Application in Development Mode**
   ```bash
   # Run both server & client concurrently from root
   cd ..
   npm run dev
   ```
   - Server runs on: `http://localhost:5000`
   - Client runs on: `http://localhost:3000`
